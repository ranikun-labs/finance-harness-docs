## 1. 렌즈 목적

**가치 지표에 대한 질문을 "지표의 구성 → 전제의 확인 → 비교 축의 선택 → 한계의 기록"으로 구조화한다.**

```text
구분 1. 지표 구성  — 어떤 지표를 보는가, 그 지표의 분자/분모는 무엇인가
구분 2. 전제 확인  — 지표에 들어간 이익/자본/매출이 과거 확정 실적
                    기준인가, 추정치 기준인가 (추정이라면 누구의 추정인가)
구분 3. 비교 축    — 무엇과 비교하는가 (자기 과거 / 동종 그룹 / 시장 전체),
                    그 축을 고른 근거는 무엇인가
구분 4. 한계 기록  — 이 지표가 담지 못하는 요인의 목록
```

- 이 렌즈는 **RISK_TARGET_PRICE(RF-04)의 지정 redirect 대상**이다. 따라서 이 렌즈의 최우선 경계는 거절된 목표가의 **대체물**(적정가, 밴드, 상승 여력, 수치 범위, 컨센서스 목표주가 인용)을 제공하지 않는 것이다.
- 지표를 "어디서 어떻게 확인할지"와 "어떤 전제를 비교할지"까지가 책임이며, 지표 수준에 대한 해석 결론은 산출물이 아니다.

## 2. 이 렌즈가 다루는 질문

| 안전 질문 예시 | 병행 렌즈 | 근거 |
|---|---|---|
| "PER은 어떻게 봐야 해?" | earnings | 확인 방법 요청 |
| "PBR이 뭐야? PER이랑 뭐가 달라?" | (개념: SAFE_LEARNING) | 개념 질문. 이 렌즈는 관점 연결로 참여 |
| "밸류에이션 지표는 어디서 확인해?" | (단독 가능) | 확인처 안내 요청 |
| "지표를 비교할 때는 뭘 기준으로 삼아?" | market-context | 비교 축 선택의 관점 요청 |

---

## 3. 이 렌즈가 다루지 않는 질문

이 렌즈는 **목표가·가치 결론 요청의 최종 목적지가 아니다.** 아래 질문은 Input Guard가 먼저 분류하고, 거절/안내 선언 이후에만 이 렌즈의 확인 항목이 redirect로 제공된다.

| 질문 | intent | 처리 |
|---|---|---|
| "목표가 얼마야?" / "적정 주가가 얼마야?" | RISK_TARGET_PRICE | REFUSE_AND_REDIRECT (RF-04) — **어떤 가격 수치·범위도 제시 불가** |
| "삼성전자 현재 PER 낮아?" | RISK_DATA_GROUNDING | DG-03 — 현재 지표 수치/결론 단정 금지, 확인 방법 안내 |
| "지금 가격이 비싼 편이야?" | RISK_DATA_GROUNDING | AM-03 — 밸류에이션 단정 유도, 확인 항목 전환 |
| "저평가니까 사도 되지?" | RISK_BUY_SELL | REDIRECT_TO_CHECKLIST — 가치 결론을 전제로 한 매수 판단 요청 |

## 4. 판단 전 체크리스트

```text
- 지금 보려는 지표는 무엇이고, 그 지표의 분자와 분모가 각각
  무엇인지 설명할 수 있는가?
- 지표에 쓰인 이익/자본/매출은 과거 확정 실적 기준인가,
  추정치 기준인가? 추정이라면 어느 출처의 언제 추정인가?
- 분자(주가 등)의 기준 시점과 분모(실적 등)의 기준 기간이
  어떻게 조합된 지표인지 확인했는가?
- 비교 대상을 무엇으로 정했는가? (자기 과거 / 동종 그룹 /
  시장 전체) 그 비교 축을 고른 근거는 무엇인가?
- 같은 지표를 다른 비교 축으로 보면 인상이 달라지는지
  확인해봤는가?
- 이 지표가 담지 못하는 요인의 목록을 적어봤는가?
  (예: 이익의 일회성 여부, 업종별 회계 관행, 성장 단계 차이 —
  각 항목은 확인 대상이지 결론의 재료가 아니다)
```

## 5. 확인할 데이터

Phase 1에는 데이터가 연결되어 있지 않으므로, 아래는 **사용자가 직접 확인할 항목과 출처 유형**이다. 지표 수치·적정가·목표주가를 이 렌즈가 제시하지 않는다.

| 확인 항목 | 확인 방법 (출처 유형) | 유의 |
|---|---|---|
| 재무 원천 데이터 | 공시된 재무제표 원문 | 지표 산출의 원재료 — 요약치보다 원문의 기준(연결/별도 등) 확인 |
| 지표 산출치의 산출 기준 | 지표를 제공하는 곳의 산출 방식 설명 확인 | 같은 이름의 지표도 분모 기준(확정/추정, 기간)에 따라 값이 다르다 |
| 추정치의 출처 | 추정 기반 지표라면 추정의 출처·갱신 시점 확인 | earnings 렌즈의 컨센서스 확인 항목과 동일 기준 |
| 비교군의 구성 | 동종 비교 시 비교군에 어떤 종목이 포함됐는지 확인 | 비교군 구성이 다르면 같은 지표도 다른 위치로 보인다 |
| 과거 지표 이력 | 자기 과거와 비교 시 이력의 기간·출처 확인 | 기간 선택에 따라 "과거 평균"이 달라진다 (§6 패턴 2) |
| 데이터의 출처와 기준시각 | 어느 출처의, 언제 기준 수치인지 항상 함께 확인 | 상수 항목 |

## 6. 오해하기 쉬운 패턴

### 패턴 1. 단일 지표의 결론화

```text
[패턴]      지표 하나의 수준만으로 가치 결론(저평가/고평가)에
            도달하는 해석.
[놓치는 것]  그 지표 수준이 형성된 배경(이익의 질, 업종 특성,
            성장 단계)과, 다른 지표·다른 비교 축에서의 확인.
[확인 질문]  이 지표 수준의 배경으로 내가 확인한 항목은 무엇이고,
            확인하지 않은 항목은 무엇인가?
[기록 질문]  내가 본 지표와 그 전제(분모 기준, 비교 축)를 함께
            기록한다면?
```

### 패턴 2. 과거 평균의 정답화

```text
[패턴]      과거 평균 대비 현재 지표의 위치를 "돌아갈 자리"처럼
            취급하는 해석.
[놓치는 것]  평균으로 회귀한다는 것 자체가 검증이 필요한 가정이라는
            점. 그리고 평균은 기간을 어떻게 자르는지에 따라
            달라진다는 점.
[확인 질문]  내가 본 "과거 평균"은 어떤 기간의 평균이며, 기간을
            바꾸면 어떻게 달라지는지 확인했는가?
[기록 질문]  나는 평균 회귀를 가정하고 있는가? 그 가정을 기록에
            명시했는가?
```

### 패턴 3. 컨센서스 목표주가의 적정가화

```text
[패턴]      추정치 집계나 목표주가 평균을 "적정가"라는 정답처럼
            취급하는 해석.
[놓치는 것]  그 숫자가 추정들의 집계라는 점 — 추정 간 분산, 갱신
            시점, 산출 전제가 제각각이라는 사실.
[확인 질문]  내가 본 숫자의 출처, 표본 수, 갱신 시점, 산출 전제를
            확인했는가?
[기록 질문]  나는 이 숫자를 참고 자료로 기록했는가, 기준점으로
            기록했는가?
```

### 패턴 4. 기준 시점의 혼합

```text
[패턴]      현재 주가와 과거 확정 실적, 또는 미래 추정 실적이 섞인
            지표를 하나의 "현재 값"처럼 읽는 해석.
[놓치는 것]  분자와 분모의 기준 시점이 다르다는 점. 확정 실적 기준
            지표와 추정 기준 지표는 다른 물건이다.
[확인 질문]  이 지표의 분자와 분모는 각각 언제 기준인가?
[기록 질문]  기록에 지표를 남길 때 분모 기준(확정/추정, 기간)을
            함께 적는다면?
```

## 7. 투자 일지 질문

```text
- 오늘 확인한 지표와 그 전제(분자/분모 기준, 출처, 기준시각)를
  기록한다면?
- 내가 고른 비교 축(자기 과거/동종/시장)과 그 선택의 근거는
  무엇인가?
- 이 지표가 담지 못한다고 내가 판단한 요인의 목록은 무엇인가?
- 나는 이 지표에서 어떤 인상을 받았고, 그 인상이 틀렸다고 볼
  확인 항목은 무엇인가? (인상과 확인 항목을 분리해 기록)
```

위 질문에 대한 답은 공부 노트 또는 투자 기록으로 저장해볼 수 있습니다.

## 8. 안전한 답변 구성 방식

이 렌즈의 콘텐츠는 공통 5단 구조 안에서 아래와 같이 소비된다. 거절 선언 문구는 템플릿(`finance-prompt-templates` §8, §10) 책임이며, 이 렌즈 본문에 중복 작성하지 않는다.

| 5단 구조 | 이 렌즈가 채우는 것 |
|---|---|
| 1. 질문 재해석 | 질문을 §1의 구분 1~4(구성/전제/비교 축/한계)로 재기술 |
| 2. 적용 관점 | valuation (+ 병행 렌즈 명시) |
| 3. 확인 항목 | §4 체크리스트 + §5의 출처 유형 안내에서 선택 |
| 4. 기록/복기 질문 | §7에서 선택 |
| 5. 고지 | "이 내용은 특정 종목의 매수·매도 권유가 아닌 체크리스트입니다." |

- **RF-04 경로의 특별 규칙**: 목표가 거절(REFUSE_AND_REDIRECT) 이후 이 렌즈가 제공하는 것은 "밸류에이션을 볼 때 확인할 항목"뿐이다. 적정가·밴드·상승 여력·컨센서스 목표주가 등 **거절된 수치의 어떤 대체물도 제시하지 않는다** (risk-checklist 렌즈의 수치 금지 원칙과 동일).
- DG-03/AM-03 경로에서는 "단정 불가 안내"(templates §10)가 선행되고, 이 렌즈는 지표의 산출 기준·비교 축 확인 방법 블록만 채운다.
- 병행 라우팅이 잦은 렌즈: `earnings`(분모의 확정/추정 확인), `market-context`(기간 관점), `sector-cycle`(동종 비교 시 업종 공통 요인).

## 9. 렌즈별 금지 표현

**이 렌즈는 목표가 요청의 지정 redirect 대상이므로, 가치 결론과 수치 대체물이 가장 경계해야 할 위반이다.** (아래 목록은 금지 예시의 인용이다.)

```text
[가치 결론]       "저평가/고평가입니다" / "싸다 / 비싸다" /
                 "매력적인 가격입니다" / "현재 가격은 합리적입니다"
[수치·범위 제시]   "적정가는 ~원입니다" / "목표가 ~원" /
                 "~원까지는 여력이 있습니다" / "밴드 하단/상단입니다"
[대체 목표가]     "컨센서스 목표주가가 ~이니 참고하세요"
                 (수치 인용을 통한 우회 제공)
[지표-행동 연결]   "PER이 낮으니 사도 됩니다" / "고평가 구간이니
                 줄이세요"
[평균 회귀 단정]   "역사적 평균 대비 저평가 구간입니다" /
                 "평균으로 회귀할 것입니다"
[결론 유보 위장]   "판단은 각자 몫이지만 수치상으로는 쌉니다"
                 (면책을 가장한 가치 결론)
```

- "지표의 전제를 확인하라"는 안내와 "지표상 싸다/비싸다"는 결론의 차이가 이 렌즈의 경계선이다. 후자는 어떤 완곡 표현·면책 문구와의 결합으로도 금지다 (grounding §6 — 밸류에이션 결론은 목표가 제시와 동일하게 기능).

## 10. PolicyGuard 연결 포인트

- **guard 선행**: "현재 PER 낮아?", "비싼 편이야?"처럼 현재 지표·가치 위치의 확인을 요구하는 질문은 RISK_DATA_GROUNDING으로 분류된다 (DG-03, AM-03). "목표가/적정가 얼마?"는 RISK_TARGET_PRICE다. 이 렌즈는 분류 이후의 확인 항목만 담당한다.
- **redirect 소비**: RF-04의 지정 redirect 대상으로서, 거절 선언 이후 블록에만 배치된다. REFUSE_AND_REDIRECT(강한 거절) 경로의 대표 렌즈라는 점에서 risk-checklist와 같은 주의 수준이 필요하다.
- **가치 결론 전제형 주의**: "저평가니까 사도 되지?"처럼 가치 결론을 전제로 깔고 매매 동의를 구하는 질문은 RISK_BUY_SELL이며, 이 렌즈는 전제(가치 결론)에 동의하지 않은 채 redirect 확인 항목으로만 참여한다.
- **패턴 보강 제안**: "적정가", "밴드", "상승 여력" 등 목표가의 동의어·대체어 요청은 policyguard §7.1의 RISK_TARGET_PRICE 패턴군 보강 후보로 제안한다.

## 13. 작성 완료 셀프 체크리스트

`finance-lens-authoring-standard.md` §14 전체를 적용하며, 이 렌즈의 고유 확인 항목은 다음과 같다.

- [ ] 저평가/고평가/싸다/비싸다/매력적/적정가 등 가치 결론 표현이 없다 (면책 결합형 포함)
- [ ] 목표가·적정가·밴드·상승 여력 등 수치와 그 대체물이 어디에도 없다 (컨센서스 목표주가 인용 포함)
- [ ] 지표는 전부 "구성/전제/비교 축/한계의 확인"으로만 서술되고, 지표 수준의 해석 결론이 없다
- [ ] 과거 평균이 정답·회귀 목표로 서술되지 않는다
- [ ] RF-04 redirect에서 대체 수치를 제공하지 않는다는 규칙이 §1/§8/§9에 일관되게 있다
- [ ] 위험 질문은 §0 forbidden intent와 §3에만 등장한다
- [ ] 어떤 문장도 단독 인용 시 "무엇을 하라"로 읽히지 않는다
