# F3-01 인벤토리와 검수 상태

이 표는 UX 검수의 route × state 인벤토리이며 완료 기준의 분모다. 모든 행은 아래 세 상태 중 하나를 가지고, 미검수로 남은 행은 없다. 데이터는 모두 fixture·mock이고 실제 백엔드는 쓰지 않았다.

- `검수함 · 직접 조작`: 검수자가 브라우저에서 화면을 직접 조작하고 캡처를 봤다.
- `검수함 · 자동 측정만`: 자동 감사(넘침, 대비, 터치 대상, 작은 글자)만 거쳤다. 14~15개 뷰포트 × Light/Dark이며 시각 판단은 없다.
- `검수 못 함(사유)`: 검수하지 못했다. 사유를 적었다.
- Carelog: 총 34행, `검수함 · 직접 조작` 13, `검수함 · 자동 측정만` 7, `검수 못 함` 14
- Finance: 총 29행, `검수함 · 직접 조작` 15, `검수함 · 자동 측정만` 6, `검수 못 함` 8

결과 열은 `PASS`, 종합 메모의 Finding ID, 검수 못 함의 `—` 중 하나다. 포커스 표시 Finding(C-06, F-06)은 Strong 버튼이 있는 모든 화면에 공통이며(X-01), 직접 확인한 대표 행에만 적었다.

## 검수 못 한 것 요약

### Carelog
- 준비 중 화면 4개(`/app/follow-ups`, `/app/reviews/:id`, `/app/customers/:id/import`, `/app/customers/:id/handoff`): 화면에서 가는 링크가 없고 URL로만 열린다.
- 인증 복구·부트스트랩 오류 상태.
- 회원가입 실패·성공.
- Assistant 답변·오류·사용 불가·메모 저장.
- 일정 수정 폼의 시각 확인.
- 로그아웃 뒤 화면.
- 일정 상세 로드 오류의 시각 확인.
- 이탈 확인(leave-confirm)은 제품에 없다. Finding C-05.
- 인벤토리의 리디렉션 경로(`/`, `/auth`)와 `/auth/*`, `/app`은 별도 화면이 없거나 다른 행과 같은 화면이라 행 단위로는 검수 못 함으로 적었다.

### Finance
- 영어 화면(`/en`, 앱 영어): 전환 UI가 없다.
- `/:locale/learn/*`.
- 목록 더 불러오기와 그 오류.
- 401 처리.
- 복기 충돌(409)과 낡은 revision.
- 기록 수정·삭제·복원 흐름: 비운영 플래그 기능이며 무스타일 상태만 확인했다(F-05).
- 검토에서 학습 노트로 이어가기.
- 저장 직후 재조회: mock 응답 형식 문제로 확인 불가.
- production 문구 하니스.
- 루트 리디렉션(`/`)은 자체 화면이 없다.
