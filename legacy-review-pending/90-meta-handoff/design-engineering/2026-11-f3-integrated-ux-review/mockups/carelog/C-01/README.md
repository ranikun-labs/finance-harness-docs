# C-01 고객 상세가 정리 필요 일정을 숨긴다 (제안 시안 · 계약 아님)
- **문제**: 예정 시각이 지난 예정 일정(정리 필요)이 고객 상세에 나오지 않고 '다음 일정 없음'으로 보인다.
- **바꾼 것**
  - 다음 일정 블록이 지난 예정 일정을 먼저 보여 준다.
  - 정리 필요일 때만 Strong '기록 완료'를 둔다.
  - 섹션 머리에 건수(정리 필요 1건)를 표시한다.
- **바꾸지 않은 것**: 상태 3개와 파생 Overdue 계약, 타임라인(기록됨 투영), 화면 순서.
- **필요한 승인**: 없음(표시 규칙 수정).
