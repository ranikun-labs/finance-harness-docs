# C-03 일정 화면 진입 시 '+ 일정'과 정리 필요 안내가 화면 밖 (제안 시안 · 계약 아님)
- **문제**: 일정 화면은 오늘로 자동 스크롤돼 열리는데, '+ 일정'과 '정리 필요한 일정 N개' 안내가 머리와 함께 화면 밖(약 900px 위)에 있다. 맨 위로 올라가면 선택 날짜가 과거로 바뀌어 새 일정의 기본 예정 시각이 과거가 된다.
- **바꾼 것**
  - 주간 띠와 같은 고정 영역에 '+ 일정'과 정리 필요 안내를 둔다.
  - 새 일정 기본 시각은 선택 날짜가 과거면 오늘 기준 다음 정시로 한다(문서 규칙).
- **바꾸지 않은 것**: 오늘로 자동 스크롤, 주간 띠, 행 구조, 하단 내비.
