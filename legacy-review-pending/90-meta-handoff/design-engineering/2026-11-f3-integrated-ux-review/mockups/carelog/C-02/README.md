# C-02 취소 처리가 확인 없이 즉시 적용된다 (제안 시안 · 계약 아님)
- **문제**: '취소 처리'를 누르면 확인 없이 바로 취소됨 상태가 되고 되돌릴 수 없다. '수정' 바로 옆 8px에 있다.
- **바꾼 것**
  - 기록 완료와 같은 인라인 확인 패널을 둔다.
  - 확정 버튼만 위험색으로 한다.
  - 취소 처리를 수정에서 떼어 오른쪽 끝으로 옮긴다.
- **바꾸지 않은 것**: 새 Dialog를 만들지 않음, 상태 계약, 취소 시 예정 시각 보존.
- **필요한 승인**: 인라인 확인은 없음. 취소 복구 기능을 만들지는 Owner 결정.
