# F-02 작성 화면에서 입력란이 검토 맥락 뒤로 밀린다 (제안 시안 · 계약 아님)
- **문제**: 작성 화면의 첫 입력란이 약 1,150px 아래에 있다. 검토 맥락 블록이 폼보다 먼저 온다. UX 계약의 표시 순서(대상 → 행동 → 이유 → 감정 → 기록 시점 → 검토 맥락)와 폰에서 맥락을 접을 수 있어야 한다는 조건과 다르다.
- **바꾼 것**
  - 맥락은 맨 위에 한 줄 요약(접힘)만 두고 본문은 폼 아래로 보낸다.
  - 첫 화면에 대상·판단·이유가 보인다.
- **바꾸지 않은 것**: 맥락 선택이 작성 화면에 있다는 결정, 필드와 선택지, 저장 계약.
- **필요한 승인**: 없음(계약 순서 복원).
- 파일: before.png / after.html(첫 화면) / after.png / after-2.html·after-2.png(전체 길이) / compare.png
