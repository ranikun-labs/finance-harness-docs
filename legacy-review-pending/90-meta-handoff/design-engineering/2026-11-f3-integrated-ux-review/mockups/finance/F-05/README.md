# F-05 수정·삭제·복원 컨트롤이 스타일 없이 노출된다 (제안 시안 · 계약 아님)
- **문제**: 수정·삭제·삭제한 기록 컨트롤이 스타일 없이 렌더된다. 상세 화면 맨 위에 삭제 안내 문단과 24px 높이 버튼이 제목보다 먼저 나온다. 비운영 참조 인증 플래그 뒤에 있어 기본 빌드에는 나오지 않는다.
- **바꾼 것**
  - 수정·삭제를 앱바의 텍스트 버튼으로 옮긴다.
  - 삭제 안내는 확인 대화상자 안으로 옮긴다.
  - 목록의 '삭제한 기록'은 목록 끝의 텍스트 링크로 둔다(문서 규칙, 시안에는 상세만).
- **바꾸지 않은 것**: 삭제는 숨김이며 복원 가능하다는 정책 문구의 뜻, 복기 진입.
- **필요한 승인**: 없음(플래그를 열기 전에 적용).
- 파일: before.png / after.html / after.png / after-2.html·after-2.png(삭제 확인) / compare.png
